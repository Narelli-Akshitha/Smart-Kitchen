# 🍳 Smart Kitchen

## About the Project

Smart Kitchen is a beginner-friendly cooking and recipe website designed especially for college students and people living away from home. It helps users discover recipes, explore ingredients, and learn what dishes they can prepare using the groceries available to them.

The main goal of this project is to make cooking easier, more convenient, and more enjoyable for students who want to prepare food on their own.

## ✨ Features

- **Veg Recipes:** Explore different vegetarian dishes.
- **Non-Veg Recipes:** Discover non-vegetarian food options.
- **Tiffins:** Find simple breakfast and tiffin recipes.
- **Snacks:** Explore tasty snack ideas.
- **Sweets:** Discover sweet recipes.
- **Pickles:** Explore vegetarian and non-vegetarian pickles.
- **Grocery Guide:** Learn about common groceries and cooking ingredients.
- **Ingredient Search:** Find possible dishes using available ingredients, if supported by the application.
- **Cooking Tips:** Learn useful kitchen tips and cooking ideas.

## 🛠️ Technologies Used

- HTML – To create the structure of the website.
- CSS – To design and style the web pages.
- JavaScript – To add interactive features and recipe functionality.

## 🎯 Project Objective

The objective of Smart Kitchen is to help college students learn basic cooking, understand ingredients, and discover easy recipes without needing complicated cooking knowledge.
